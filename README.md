# 🌿 HealthKu - Personal Health & Athletic Coach

Aplikasi Android native (Kotlin + Jetpack Compose) untuk memantau kesehatan, denyut jantung, tidur, dan aktivitas olahraga yang disinkronkan langsung dari Smartwatch (SKMEI DM56 / GloryFit Pro) via **Android Health Connect**, ditenagai oleh **AI Athletic Coach (Tegas & Saintifik)**.

---

### ✨ Fitur Utama
1. **Desain UI/UX Warm Organic & Sage Green (Asclepios Theme)**
   - Hero Health Score (Readiness Score 1–100).
   - Kalender strip mingguan dengan status aktif.
   - Grafik gelombang (*Wave Sparkline*) untuk Heart Rate, Blood Pressure, Tidur, dan Jarak.
2. **AI Athletic Coach (Tegas + Saintifik)**
   - Morning Protocol Briefing: Analisa kualitas tidur (Deep Sleep ratio), Resting Heart Rate, dan kesiapan sistem saraf pusat (CNS).
   - Evening Debrief: Evaluasi pencapaian langkah harian dan kunci jam tidur optimal.
   - Dynamic Step Target: Rekomendasi langkah otomatis menyesuaikan menu latihan (Angkat Beban: 7.000 langkah, Lari: 11.000 langkah, Jalan Cepat: 8.500 langkah).
3. **Integrasi Resmi Android Health Connect**
   - Membaca data langsung dari ekosistem Health Connect yang disinkronkan oleh GloryFit Pro.
   - 100% aman dan berjalan di perangkat lokal pribadi.
4. **Cloud Build Otomatis via GitHub Actions**
   - Setiap ada update kode di repository ini, GitHub Actions akan otomatis merakit file `.apk` siap unduh di tab **Releases**.
